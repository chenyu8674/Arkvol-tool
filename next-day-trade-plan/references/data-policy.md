# 台股数据策略

## 定位

以 `yfinance` 作为统一采集入口，不作为唯一事实来源。公告、重大合同、业绩与监管结论必须回到公开资讯观测站（MOPS）、台湾证券交易所、证券柜台买卖中心或公司原文核验。每次运行必须记录库版本、生成时间、组件状态、底层来源和错误。

## 组件与接口

| 组件 | 首选接口 | 主要用途 | 失败影响 |
|---|---|---|---|
| 前复权行情 | `yfinance.history(auto_adjust=True)` | 指标和关键价位 | 硬失败，停止具体价位 |
| 未复权行情 | `yfinance.history(auto_adjust=False)`；上市股票可降级 `TWSE STOCK_DAY` | 核对最新 OHLC | 硬失败，停止具体价位 |
| 公司资料 | `yfinance.Ticker.info` | 名称、产业与基础识别 | 可降级人工识别 |
| 公司新闻 | `yfinance.Ticker.news` | 新闻候选池 | 降低新闻置信度 |
| 行业新闻 | 人工检索 + 媒体/MOPS | 产业新闻候选池 | 降低行业判断置信度 |
| 公告线索 | MOPS 公开资讯观测站 | 正式公告与重大讯息 | 高影响事项必须原文核验 |
| 个股研报 | 券商/研究门户（无捆绑 API） | 评级与预期变化 | 报告“无研报数据” |
| 盈利预测 | 公开一致预期（若可得） | EPS 与评级预期 | 报告“无一致预期” |

## 行情硬门槛

1. 拉取至少 250 根、最低 60 根前复权日线。
2. 获取同一证券、同一截止日的未复权行情。
3. 前复权与未复权最后一日 OHLC 逐项误差不得超过当日最小跳动单位（tick）。
4. 最后日期必须等于最近已完成台股交易日；停牌或无成交需有明确解释。
5. 任一门槛失败时不生成支撑、压力、止损或仓位触发价。

## 代码与市场

- 代码统一为 `NNNN.TW`（上市，TWSE）或 `NNNN.TWO`（上柜，TPEx）；ETF 等可为 4–6 位。
- 未带后缀的裸代码不得猜测写入；要求用户补全 `.TW` / `.TWO`。
- 交易日历使用台股日历（Asia/Taipei），不得套用 A 股或美股假期。

## 新闻与公告

Yahoo 新闻只是候选池，不是最终证据。对以下高影响事项必须打开原始链接核验：财报、重大合同、增减持、库藏股、监管处分、诉讼、事故、停复牌、处置/注意股票、全额交割、资本与股利政策变化。

行业新闻必须先确认公司产业与主营产品，再结合供应链环节检索。宽泛主题关键词只能作为线索，不能直接认定公司受惠。

## 研报与盈利预测

- 默认观察最近 30 日新增研报、评级调整、预测 EPS/净利润变化和覆盖机构数。
- 研报观点属于市场预期，不属于公司已确认事实。
- 无可靠 API 时明确标记缺失，不得从无来源网页拼接观点。

## 降级顺序

1. yfinance 接口重试并记录错误。
2. 上市股票未复权日线可降级到证交所 `STOCK_DAY` 公开资料；上柜股票优先维持 yfinance 或改查柜买中心公开资料。
3. 公告和重大新闻回到 MOPS、证交所/柜买中心、公司官网。
4. 研报接口失败时直接标记缺失。
5. 单只股票或单一组件失败不阻断组合中其他股票。

## 自动简报状态

每次 08:30（Asia/Taipei）简报必须显示：关注标的数、行情成功数、新闻成功数、研报成功数、失败标的与组件、统一行情截止日、新闻检索截止时间和 yfinance 版本。
