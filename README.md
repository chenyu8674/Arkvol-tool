# 五子棋（原生 JS）

纯原生 JavaScript（ES Module）实现的五子棋前端应用，不依赖任何第三方库，也不需要构建。

## 功能

- 人机对战：6 档 AI（入门 / 初级 / 中级 / 高级 / 专家 / 大师），AI 在 Web Worker 中运行，不阻塞界面
- 特殊规则：
    - 黑棋禁手（三三、四四、长连），恰好五连优先于禁手；界面用红叉标出禁手点
    - 让子：黑棋天元之外再预置 1~8 子，由白棋先走
    - 棋盘大小：9 ~ 19 任意选择
- 提示、悔棋
- 复盘评估：逐手对比引擎最佳着法，给出胜率损失、准确度、失误统计、胜率曲线和估计档位

## 运行

```bash
npm start        # 启动静态服务器，打开 http://localhost:8080/
npm test         # 运行单元测试（Node 内置 test runner）
```

ES Module 与 Worker 需要通过 HTTP 访问，不能直接双击 `index.html`。也可以用任意静态服务器，例如 `python3 -m http.server`。

## AI 设计

- 估值：把棋盘上所有长度为 5 的窗口（四个方向）作为单位，增量维护双方子数，落子 / 撤子只更新经过该点的至多 20 个窗口。
- 搜索：Negamax Alpha-Beta，候选点限制在已有棋子 2 格范围内，按攻防得分排序并限制每层宽度；置换表、迭代加深、时间控制。
- 战术：
    - 己方有五连点直接取胜，对方有五连点必须封堵（强制着法）
    - 叶节点对强制着法做静态延伸，避免水平线效应
    - VCF（连续冲四）必胜搜索：根节点用较深的 VCF，叶节点用浅层 VCF 识别对方杀棋
- 禁手：黑棋走法生成、VCF 与封堵判断都会过滤禁手点；VCF 中白棋可利用黑棋被迫落在禁手点的情况。
- 难度：通过搜索深度、时间、宽度、VCF 深度和根节点软最大随机（噪声）组合。

## 棋力评估

两种方式：

1. 引擎自身棋力（`npm run arena -- --a 3 --b 4 --games 20`）：随机开局、交换先后手，用胜率换算 Elo 差。当前一次小样本结果（15×15，自由规则，样本小，误差约 ±150）：

    | 对局 | 较弱方得分 | 估计 Elo 差 |
    |---|---|---|
    | 1 档 vs 2 档 | 17% | -280 |
    | 2 档 vs 3 档 | 5% | -510 |
    | 3 档 vs 4 档 | 30% | -150 |
    | 4 档 vs 5 档 | 38% | -90 |
    | 5 档 vs 6 档 | 33% | -120 |

2. 玩家棋力（界面「复盘评估」）：对每一步用同一深度搜索最佳着法和实战着法，以胜率差作为损失。`scripts/calibrate.js` 用各档 AI 自对弈标定的平均损失为：1 档 7.1%、2 档 7.0%、3 档 2.7%、4 档 0.0%、5 档 0.4%、6 档 0.9%。
   复盘引擎只搜索 6 层，因此对高级以上的区分度有限，界面只给出粗略档位。
